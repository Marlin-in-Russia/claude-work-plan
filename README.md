# План работ — мод для Claude Code

Панель «План работ» рядом с чатом. Агенты составляют в ней план, ставят статусы и пишут комментарии по ходу работы. Вы видите прогресс, меняете статусы, отвечаете на комментарии и держите бэклог задач на потом.

## Возможности

- **План по этапам**: задачи со статусами «В плане», «В работе», «На проверке», «Блокер», «Готово», «Отменено», исполнителем и лентой событий.
- **Прогресс**: процент готовности, полоса по статусам, счётчики по этапам.
- **Несколько сессий в одном проекте**: у каждой сессии свой план, планы не мешают друг другу. Вкладка «Планы проекта» показывает планы всех сессий; любой можно открыть или подключить к своей сессии, чтобы её агент продолжил его.
- **Бэклог**: задачи на потом с приоритетами, общие для всех сессий проекта. Задачу можно взять в план, а из плана отложить обратно.
- **Обратная связь**: смена статуса, комментарий или новая задача в панели доходят до агента той сессии, чей это план.
- **Файл в проекте**: планы и бэклог хранятся в `.claude/work-plan.json`. Это читаемый JSON, правки руками подхватываются панелью. Одновременная запись из нескольких сессий безопасна: файл перечитывается прямо перед записью. Закоммитьте его, чтобы планы видела команда, или добавьте в `.gitignore`.

## Установка

В терминальной сессии Claude Code:

```
/plugin install work-plan --marketplace Marlin-in-Russia/claude-work-plan
```

Ответьте `y` на «Add marketplace?», затем выберите область установки (user — для всех проектов).

Из командной строки:

```
claude plugin install work-plan --marketplace Marlin-in-Russia/claude-work-plan
```

В приложении Claude Desktop, где `/plugin` не работает: нажмите + рядом с полем ввода, затем Plugins, Add marketplace с `Marlin-in-Russia/claude-work-plan`, затем Add plugin.

Репозиторий приватный: мод установится только у тех, у кого есть доступ к нему на GitHub и настроены git-учётные данные для github.com (SSH-ключ или `gh auth login`, затем `gh auth setup-git`). Установка сама их не запрашивает.

### Обновление

```
claude plugin update work-plan@claude-work-plan
```

Затем `/reload-plugins` или перезапуск в каждой открытой сессии. Версия 0.3 пишет файл в новом формате, который 0.2 не понимает, поэтому обновите все сессии проекта сразу. План версии 0.2 появится во вкладке «Планы проекта» как P1 «без сессии»: подключите его к нужной сессии.

## Как пользоваться

Попросите агента: «составь план работ и веди его в панели». Дальше агент сам отмечает статусы и пишет комментарии. Фразы «добавь в бэклог …» и «возьми B2 в работу» работают с бэклогом, «продолжи план P2» — с планом другой сессии.

`/work-plan` открывает панель, `/work-plan clear` убирает план этой сессии в архив (бэклог и планы других сессий остаются).

### Инструменты агентов

| Инструмент | Что делает |
| --- | --- |
| `plan_set` | Создаёт план этой сессии; прежний уходит в архив, незавершённое можно отложить в бэклог |
| `plan_update` | Статусы, комментарии, правки задач, перенос в бэклог |
| `plan_add` | Добавляет задачи в план |
| `plan_get` | Читает план сессии, список других планов и бэклог вместе с вашими изменениями |
| `plan_open` | Подключает сессию к плану проекта: другой сессии, прежней или архивному |
| `backlog_add` | Кладёт задачи в бэклог |
| `backlog_update` | Правит задачи бэклога, приоритет, комментарии |
| `backlog_promote` | Берёт задачи из бэклога в план |

Инструменты плана по умолчанию работают с планом своей сессии; `plan_id` направляет их в другой план.
